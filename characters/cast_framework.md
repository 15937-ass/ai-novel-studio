# Cast Framework — 人物底模与成长原则

> 状态：HARD（角色编号/功能/成长原则） / OPEN（姓名、具体家庭背景、完整感情线）

## 1. 总成长原则

人物必须拥有长期人生，而不是只为世界观服务。

核心成长路径：

```
学生
→ 社会工作者
→ 跨机构协调者
→ 公共人物
→ 承担文明级责任的人
```

并非所有主要人物都走到最后一级。

群像关系可以经历：
**形成 → 分裂 → 离散 → 重组**

不同人物必须在家庭、金钱、体面、爱情、职业、恐惧、野心、责任之间做不同选择。

禁止：
- 所有人都愿意为“大义”牺牲；
- 主角团永远道德正确；
- 反对主角的人自动等于坏人；
- 配角只为主角成长而存在。

## 2. 成长机制参考

对话明确提出借鉴以下作品的“成长机制”，不是复制剧情或文风。

### 《哈利·波特》
参考：
- 年龄真实增长；
- 教育阶段变化；
- 社会身份变化；
- 每卷承担更大责任；
- 同一群人在时间中变成不同的人。

### 《龙族》
参考：
- 青春感与普通人的不体面；
- 孤独、欲望、犹豫与热血并存；
- 热血不是口号，而来自沟通、尊重、承担以及面对自己的脆弱。

### 《斗罗大陆》《斗破苍穹》
参考：
- 阶段性正反馈；
- 新能力/新世界/新规则门槛逐层打开；
- 伙伴关系随成长变化；
- 读者持续感到“人物真的走远了”。

不采用：
- 直接照搬境界系统；
- 套用桥段；
- 单纯数值升级。

## 3. 1号 — 男主
### 定位
固定男主。

### 人格底模
**“紫破型重构者”**

核心内在句：
> 我要弄明白，然后改变。

特征：
- 强主体性；
- 对系统和规则有重构冲动；
- 胜负欲；
- 不满足于“事情一直如此”；
- 面对冲突倾向先理解结构，再试图改写结构；
- 容易把“我能解决”误认为“应该由我解决”。

### 成长弧
```
证明自己
→ 相信自己
→ 承担问题
→ 学会容纳别人拥有不同选择
→ 成为文明协调者
```

最终成长不是“控制更多”，而是学会在自己有能力重构世界时仍尊重其他主体。

## 4. 2号 — 女主
### 定位
固定女主。

### 人格底模
**“巨门型诘问者”**

核心内在句：
> 先说清楚，你凭什么这么认为？

特征：
- 对前提极敏感；
- 语言精确；
- 擅长拆解含混结论；
- 对制度、资格、证据和责任有强烈敏感性；
- 容易用理智保护情感；
- 与男主形成持续互相校正。

### 成长方向
```
质疑与拆解
→ 进入制度与公共责任
→ 从证明“我有资格质疑”
→ 到接受“不必独自证明自己的资格”
```

她不是“男主的理性辅助器”，必须拥有独立职业、关系、价值冲突与失败。

### 与男主
V1 只锁定两人的核心关系轴：
**判断 ↔ 质疑 / 重构 ↔ 证据 / 行动 ↔ 边界**

具体恋爱节奏与最终关系保持 OPEN。

## 5. 3号 — 竞争者
### 人格底模
**“贪狼—七杀型开拓竞争者”**

核心内在句：
> 既然世界在变，为什么赢的人不能是我？

功能：
- 把时代变革理解为机会；
- 与男主共享行动力，但价值排序不同；
- 不能被写成纯粹反派；
- 野心、欲望与现实成就都必须合理。

## 6. 4号 — 核心伙伴
### 人格底模
**“天机—巨门型风险思考者”**

核心内在句：
> 我不是悲观，我只是把失败也算进去。

功能：
- 系统性考虑失败路径；
- 提供不受主角热情支配的风险视角；
- 可以因为现实风险而反对主角；
- 不是“负责泼冷水”的工具人。

## 7. 5号 — 导师
### 人格底模
**“太阴—天梁型温和守序者”**

核心内在句：
> 能做，不代表应该立刻做。

功能：
- 代表经验、程序、责任与克制；
- 不是保守派稻草人；
- 在真正危机中可能比年轻人更敢承担；
- 其守序应来自看见过系统崩坏的代价，而非单纯怕变化。

## 8. 紫微斗数使用边界

对话明确规定：

- 只把全盘分析用作**性格素材**；
- 不用命盘预测角色命运；
- 不用命盘决定谁成功、谁死亡、谁恋爱；
- 不把紫微术语直接写进正文人物标签；
- 人物最终行为必须由经历、关系、制度环境与自由选择生成。
