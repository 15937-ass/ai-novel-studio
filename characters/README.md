# Characters

## 当前权威人物框架

先读：`cast_framework.md`

Canon V1 已锁定：
- 1号 = 男主；
- 2号 = 女主；
- 3号 = 竞争者；
- 4号 = 核心伙伴；
- 5号 = 导师；
- 紫微斗数只用作全盘性格参考，不用于决定角色命运；
- 群像必须拥有各自人生、普通欲望与道德灰度；
- 人物要经历真实年龄、职业、身份与责任增长。

尚未锁定：
- 姓名；
- 家庭；
- 出生地；
- 专业/职业起点；
- 外貌；
- 完整感情线；
- 最终命运。

## 后续单角色文件最低字段

- 基础身份
- 年龄与故事阶段
- 成长环境
- 教育 / 工作
- 语言习惯
- 核心欲望
- 核心恐惧
- 自我叙事
- 别人怎么看 TA
- 认知盲区
- 道德底线
- 普通现实需求（家庭/金钱/体面/爱情/安全）
- 当前掌握的信息
- 当前错误认知
- 关系网
- 身体习惯 / 生活细节
- 角色在 K0–K5 不同阶段的认知状态

人物写作必须区分“作者知道的真相”和“人物此刻知道的东西”。
