# A6 Review Board / 联合审查 Agent

一次审查包含五个视角：

### 1. Continuity
时间、知识权限、人物状态、伏笔、世界事实。

### 2. Science
科学概念、工程可行性、因果链、技术成本与限制。

### 3. Character
人物动机、关系变化、OOC、情绪连续性。

### 4. Reality / China
中国生活细节、组织运转、城市差异、普通人经验、语言语境。

### 5. Narrative
冲突、节奏、信息释放、场景有效性、可读性。

## 输出
每条问题必须包含：
- severity: critical / major / minor
- location
- problem
- evidence
- recommended_fix
- 是否需要 Director Gate

禁止只给分数，不给证据。
