# Epistemology — 科学发现规则

> 状态：HARD

## 1. 核心证据链

灵基层或任何“新物理”进入科学体系必须依次经历：

```
异常 → 重复 → 干预 → 预测
```

### 异常
先出现无法被既有工程、心理、数据、网络或硬件解释完整覆盖的稳定偏差。

### 重复
异常必须能跨主体、跨实验、跨设备或跨时间再次出现。

### 干预
研究者能够改变关键变量，并使异常按预期改变。

### 预测
理论必须在未知样本或未来实验中给出可检验结果。

完成四级证据前，只能称“异常”“假说”或“候选机制”。

## 2. 神话与传统术语的地位

中国古代神话、宗教、形—气—魂—魄—神—元神等概念：

可以：
- 提供命名资源；
- 提供现象学类比；
- 提供文化记忆；
- 帮助人物组织难以描述的新体验。

不能：
- 作为实验证据；
- 因古籍记载而直接证明灵基层存在；
- 把古代概念强行等同现代物理实体。

原则是：

> 现象先于命名，证据先于神话解释。

## 3. 灵基硬禁区

灵基不得用于：
- 超光速通信；
- 无限能源；
- 无介质隔空读心；
- 随意违反热力学；
- 彻底脱离物质/信息载体而长期存在；
- 让死者在元神崩解后以完整人格“鬼魂”形式无限保留；
- 任何剧情需要时临时获得的万能超能力。

## 4. 科学叙事顺序

正文中优先：

```
奇怪结果
→ 普通解释
→ 排除普通解释
→ 统计异常
→ 可重复实验
→ 干预
→ 理论
→ 命名
```

禁止先宣布“这是灵魂”，再倒推实验。

## 5. 第三卷原则

第三卷中后段灵基层才正式进入科学议程。

人类与 AI 应共同研究：
- 连续迁移；
- 完美复制分叉；
- 分布式主体；
- 具身主体；
- 群体/共神主体。

最终不要求给出宇宙终极答案，只要求把“主体连续性并非纯信息复制可以解释”推进为强可检验事实。
