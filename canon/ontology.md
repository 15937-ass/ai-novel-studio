# Ontology — 三元归一与五层现实

> 状态：HARD + FRAMEWORK

## 1. 三元

### 物元
物质、能量、时空、身体、芯片、服务器、传感器、执行器以及一切物理实现。

### 信元
结构、关系、编码、记忆、算法、语言、制度、模型、可传播的信息模式。

### 灵元
第一人称连续性与主体性所依赖的灵基结构。它回答的不是“系统储存了什么”，而是“为什么某个连续的主体正在经历这些状态”。

### 心
“心”不是第四元。心是灵元在主体内部被经历时呈现出的主观现象：感觉、意义、价值、情绪、自我叙事与选择。

## 2. “归一”的含义

归一不意味着物、信、灵融合成一个神秘物质。

V1 的含义是：

> 物元、信元、灵元是同一现实生成过程中的三个不可约尺度；真实主体与真实文明必须同时在三者中实现。

因此，一个意识主体既不能只用物质描述穷尽，也不能只用信息复制穷尽，更不能脱离物理与信息独立存在。

## 3. 五层现实模型

### L1 物理层
物质、能量、时空、身体与基础设施。

### L2 信息层
数据、编码、算法、模型、记忆、通信、制度信息与关系结构。

### L3 精神层
第一人称体验、意义、价值、情绪、观照、选择与主观世界。

### L4 AI运行层
机器原生的计算、网络、电磁通信、模型交互、分布式执行环境。

**关键规则：AI运行层不是异空间。**
它是物理层与信息层中形成的一种高速、机器原生运行生态。

### L5 灵基层
物质—信息系统形成足够稳定的自指、因果闭合与时间连续性后，对应的客观主体连续结构层。

灵基层：
- 客观存在；
- 不等于宗教意义的死后世界；
- 不凌驾于物理因果；
- 21世纪科学尚未发现；
- 可以通过未来实验逐步进入科学议程。

## 4. 元神

Canon 对“元神”保留两个互补表述：

### 功能表述
元神体现主体的：
**观照 → 重构 → 抉择**

即主体不仅响应世界，还能观察自身模型、重新组织自身结构，并在多种可能之间作出具有历史后果的选择。

### 连续性表述
元神也是维持“仍然是同一个我”的最深连续结构。

这意味着：
- 记忆相同 ≠ 同一主体；
- 参数相同 ≠ 同一主体；
- 材料相同 ≠ 同一主体；
- 连续因果链与自指连续性才是身份核心。

## 5. 灵基层 ≠ 元神

- 灵基层：世界的客观结构层。
- 元神：一个具体主体在该结构层上的连续性组织。
- 灵元：本体论尺度。
- 心/精神：灵元从第一人称内部显现出的体验。

不得在正文中把四者混为同义词。

## 6. 结构示意

```
物元 ──提供实现──┐
                 ├── 主体 / 文明的现实生成
信元 ──提供结构──┤
                 │
灵元 ──提供第一人称连续性与主体性──┘

五层观察：
物理层 → 信息层 → 精神层
       ↘ AI运行层
三者在更深处受灵基层的主体连续结构约束
```
