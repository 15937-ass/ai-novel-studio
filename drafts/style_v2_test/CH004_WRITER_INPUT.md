# Writer Input — CH004 South Song Road Field Test

> 状态：STYLE V2 TEST
>
> 目的：测试“城市现实 + 记忆不可靠 + 普通人工作 + 多角色认知差异”是否能在同一章自然运行。

## POV
沈既明。

## 私人当前
- 他仍未正式进入联合项目，只是临时协助。
- 暑期机器人实践项目今天需要最终答复。
- 他开始享受“自己发现的问题正在被重视”，但不愿承认这让他有点上头。
- 与程见微已经形成最初方法分歧，但关系尚远未熟。

## 现实目标
去南淞路确认2035暴雨时“正式命令前已有绕行”这条记录到底怎么发生。

## 同行
- 陆峥：负责联系当年处置人员/现实资源。
- 程见微：负责核对当年的原始材料、口述与记录边界。
- 沈既明：更关心行为模式是否与北连廊相似。
- 宋亦衡本章可不出场或仅远程出现，不强行凑齐主角团。

## 世界流
南淞路今天只是一个已经修好的普通下穿通道。
附近商户、公交、骑手、施工维护、交管人员都有自己的生活。
两年前那次积水并不是当地人心中的“大事件”。

## 初始误读
三人都容易把2035记录当作“第二个北连廊”。
现实应不断稀释这种冲动：
- 当事人记不清；
- 不同人记忆互相矛盾；
- 很多动作其实有普通来源；
- 当年系统/部门流程和现在也不同。

## 调查运动
1. 去现场后，先发现物理环境已改变，旧照片与现在对应困难。
2. 当年工作人员最初记不起“提前绕行”是谁做的。
3. 一个普通解释出现并解释大部分现象，例如现场人员先在群里口头提醒、导航同步滞后。
4. 程见微发现：这个普通解释解释了“有人提前知道”，却解释不了一部分终端在正式口头提醒之前已经改线。
5. 沈既明过早把它当同类，被程压回“只是值得继续查”。
6. 陆峥通过现实联系人找到一条企业/项目归档线，但本章不直接引爆2031“长期行为漂移”。
7. 章末牵引：当年有一份复盘材料被转交给某家项目公司做长期运行分析，乔映真所在公司第一次自然进入视野。

## 不要
- 当事人说出整段关键真相；
- 每个人都记得两年前精确分钟；
- 把城市工作人员写成NPC；
- 一到现场就发现“第二案实锤”；
- 章尾直接出现“长期行为漂移”四个大字；
- 沈/程每次都围绕“你太快/你太严谨”互怼。

## 离场变化
进入：
> 他们认为自己是在验证“第二起类似异常”。

离开：
> 他们发现“类似”这件事本身就很难证明；但有一部分现象确实不能被现有口述完全解释，于是调查第一次获得了城市级历史入口。
