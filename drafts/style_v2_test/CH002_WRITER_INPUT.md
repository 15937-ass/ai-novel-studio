# Writer Input — CH002 Blank Draft Test

> 状态：STYLE V2 TEST

## POV
沈既明为主；不切换意识中心。

## 私人当前
- 事故后的第二天，校园照常运行。
- 家庭已经知道事故，母亲确认安全；父亲更关心结构与维护，二者都不理解“神秘通知”。
- 第二选择暑期机会仍在等回复。
- 项目落选仍存在：陆峥已经开始正式入组，沈不是。

## 现实目标
最初只是按学校/梁慎之要求提交原始通知记录。
随后因为一次具体判断，被允许留下协助低权限核查。

## 其他人目标
- 陆峥：项目正式成员，需要完成繁琐的事故核查，不是侦探。
- 梁慎之：先把普通事故/信息链解释查清，不愿意过早扩大。
- 信息中心/项目人员：希望尽快分类、排除错误上报与转发。
- 程见微：可以在本章后半自然出现，她有自己的分类/数据审查任务，不是“女主登场”。

## 世界正在做什么
- 校园绕行；
- 事故通报、伤者消息、谣言；
- 课程/考试继续；
- 学校收集原始终端记录；
- 很多人其实记错自己是否收到原始提示。

## 初始误读
“学校某个自动天气/设施规则提前触发了路线调整。”

## 调查运动
1. 先解释掉一批假异常：
   - 转发截图；
   - 时间记错；
   - 普通暴雨绕行；
   - 事故后通知。
2. 沈发现一组不应该和普通暴雨提醒合并：
   内容看似一样，但来源链/动作不同。
3. 这个判断改变他的社会位置：梁允许他留下做异常验证。
4. 程见微若出现，她首先指出“我们还不能说旧接口发了通知”，并重新定义分类边界。
5. 章末只需要到：
   一个三年前退出正常发布链的历史接口出现在17:16那条记录路径里。

## 不要
- 七台手机整齐摆桌上；
- 连续权限问答；
- “真正的问题是……”类总结；
- 立刻找到2035；
- 让所有普通解释都失败；
- 把程见微写成永远正确。

## 离场变化
进入：沈只是事故相关当事人、落选学生。
离开：他因一个具体判断获得低权限参与，同时发现17:16提示的路径比预期更旧、更脏，但仍完全可以解释为工程遗留。
