# Writing Readiness — 当前能否开始写

> 当前评估：**可以开始试写，不建议直接进入正式连续生产。**

## 已具备

### 世界观
Canon V1.0 已足够稳定：
- 底层本体；
- AI主体规则；
- 数字天庭；
- 国际AI路径；
- K0→K5；
- 三卷宏观结构；
- 人物成长原则。

### 风格
已经具备：
- 可读性第一；
- 近身现实型科幻方向；
- 有限第三人称；
- 单场景意识中心；
- 中长段落；
- 因果连续；
- 思辨事件化；
- 科学解释事件化；
- 生活质感优先；
- 反碎段；
- 反说教。

这些足够支撑 **1–3个试验场景或一章试写稿**。

## 尚不足以支撑正式第一卷连续生产

### A. Style Bible v1.0 未锁

还需要至少确定：
- 叙述者温度与幽默度；
- 心理距离；
- POV正式切换规则；
- 句法/段落校准；
- 对白体系；
- 人物语言指纹；
- 抒情/哲思上限；
- 爱情、暴力、身体书写尺度；
- 正例/反例样章。

### B. 第一章的具体故事输入尚不足

Canon 已定义“世界是什么”，但真正写第一章还需要锁：
- 第一卷实际起始年份；
- 第一章所在城市/学校/组织；
- 男主姓名、年龄、家庭与当时身份；
- 女主是否第一章出现；
- 3/4/5号何时进入；
- 第一卷具体外部目标；
- 第一批5章的 Chapter/Batch Contract；
- 开场“小型资源调度异常”是否最终采用；
- 第一章结束时必须发生的不可逆变化。

### C. 第一卷人物资料仍偏底模

当前有：
- 性格底模；
- 成长方向；
- 功能关系。

仍缺：
- 生活史；
- 家庭；
- 教育背景；
- 经济条件；
- 社会关系；
- 说话方式；
- 个人癖好；
- 身体习惯；
- 真实短期欲望；
- 具体秘密/羞耻/失败经历。

这些不需要全部在全书开写前完成，但第一卷出现的角色必须先补够。

## 推荐的“开写阈值”

正式开始 Chapter 1 前，至少应完成：

1. Style Bible v1.0 最小版；
2. 男主/女主 Character Sheet v1；
3. 第一卷起始年代与现实场景；
4. 第一批 5 章 Batch Contract；
5. Chapter 1 Contract；
6. 一段 1500–3000 字试写，通过 Style + Anti-AI + Reality 三重校准。

达到这六项后，可以进入正式章节流水线。

## 结论

现在：
- **能试写。**
- **不能把试写当最终正文大规模推进。**

最缺的不是世界观，而是：
> **稳定叙事声音 + 第一卷具体人物生活 + 第一章的因果起点。**
