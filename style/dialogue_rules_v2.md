# Dialogue Rules v2 — 对话节奏硬规则

> 状态：ACTIVE CANDIDATE
>
> 解决：短问短答过多、对话像采访、节奏被切碎。

## 1. 禁止“审讯式乒乓”

出现连续：
> 问一句 / 答一句 / 再问一句 / 再答一句

达到3轮，默认视为节奏风险。

达到5轮，除非场景本身就是审讯、抢救、危机口令，否则必须重写。

## 2. 信息对话优先“打包”

如果一个角色需要确认3–5个相关信息，优先让他一次说完完整需求。

坏：
> “谁授权？”
> “梁老师。”
> “哪个项目？”
> “学校联合项目。”
> “能留副本吗？”

好：
> “我先确认一下：你们现在是梁老师项目内的调查，不是市里正式复核，对吧？如果是这样，我能帮你们找共享材料，但企业内部件不能直接留副本。”

## 3. 对话必须夹带人物意图

任何信息对话至少同时承担一项：
- 争权；
- 试探；
- 回避；
- 示好；
- 施压；
- 维护面子；
- 争取时间；
- 转移情绪。

只传信息的对话优先改成叙述。

## 4. 每段对话要有“主导权变化”

一场超过300字的对话，至少发生一次：
- 谁掌握信息改变；
- 谁掌握节奏改变；
- 谁让步；
- 谁被迫暴露立场；
- 谁提前结束对话。

如果从头到尾只是轮流问答，视为无效场景。

## 5. 短句额度

不是按数字机械限制，但Writer自检：
- 连续两行都不足8字时，第三行优先并入叙述或扩成完整表达；
- “嗯 / 对 / 然后呢 / 为什么 / 所以呢”不得成为常用节奏骨架；
- 短句要承担重音，而不是承担常规信息交换。

## 6. 叙述接管原则

以下内容优先用叙述概括，而不是逐句对话：
- 权限确认；
- 重复背景；
- 已知流程；
- 多项事实核对；
- 无冲突的会议纪要。

例如：
> 乔映真先确认了他们的授权范围。梁慎之的项目身份足够查看共享材料，却够不到企业内部报告，更不用说原始数据。她把这几层一次划清，才开始谈能帮什么。

比连续八句问答更顺。

## 7. 对话长度要有层次

同一场景允许：
- 一段完整长话；
- 一个短反应；
- 一段叙述；
- 一句打断；
- 再回到完整表达。

目标是波浪，而不是机关枪。
