# Style Status — Framework v0.8

> 来源：2026-09-27《确定小说语言风格》对话
>
> 当前结论：**风格骨架已经成立，但 Style Bible v1.0 尚未完成。**
>
> 允许：写试验场景 / 试写章 / A-B 风格校准。
>
> 不建议：在没有进一步校准的情况下直接进入整卷连续生产。

## 状态标签

- `CONFIRMED`：用户明确提出或明确接受。
- `ACCEPTED_FRAMEWORK`：助理提出后，用户整体认可方向，未否定；可作为当前工作规则，但仍可微调。
- `REJECTED`：用户明确反对。
- `PROPOSED_ONLY`：曾经提出，但没有用户确认。
- `OPEN`：尚未讨论完，正式写作前最好补齐。

## 当前已确认

### CONFIRMED
- 可读性第一。
- 思辨通过结构、冲突、选择与后果完成，不通过作者说教完成。
- 参考刘慈欣的科学/思想“事件化”能力，而不是模仿句子。
- 参考马伯庸的推进与信息揭示。
- 参考尾鱼的虚构场景可信度与悬念。
- 参考余华的乡土、人情与生活质感。
- 中长段落与连续流动叙述为常态。
- 反对过度碎段。
- 短句、短段只作重音，不能成为默认节奏手段。
- 节奏主要依靠“有效状态变化”，而不是依靠把句子切短。
- 动作—观察—判断应尽量形成连续因果链，而不是机械拆成许多碎句。
- 人物必须有成长、群像必须鲜活、善恶必须保留灰度。
- 不允许所有角色都只服务“大义”。

### ACCEPTED_FRAMEWORK
- 总体方向：**近身现实型科幻叙事**。
- 主要使用有限第三人称。
- 单场景尽量保持单一意识中心。
- 通过人物的知识边界、注意力边界和感知滤镜限制信息。
- 高概念优先通过物体、行为、制度摩擦和后果进入正文。
- 科学解释只有在会改变人物行动或读者判断时才展开。
- 低修辞基线。
- 人物少说“大词”。
- 情绪优先通过行为、身体反应、习惯、回避和关系变化承载。
- 场景与章节推进服从因果，不靠事件堆砌。
- 长篇需要局部清晰、整体保持未知边界的“森林感”。

## 明确未确认

以下内容曾由助理提出，但不能当作最终 Style Bible：

- 固定“长短句 35:65”。
- 固定“段落 2–5 句”。
- 固定“对白占比 25%”。
- 固定“华丽度 3/10、冷峻感 7/10、哲思 4/10、网络语言 1/10”。
- 固定“视觉→声音→身体感”的感官顺序。
- 固定“日常→异常→信息差扩大→认知裂缝”为每章模板。

这些属于 `PROPOSED_ONLY`，后续必须通过样章验证，而不能机械量化。
