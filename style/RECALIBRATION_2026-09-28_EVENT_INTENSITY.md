# Style Recalibration — 重大事件的现场感

> 来源：Director 对 CH001 v3 的反馈：
> “前半段比较舒服，但是后半段出事太平淡了，不够吸引人。”
>
> 状态：CONFIRMED FEEDBACK

## 问题诊断

CH001 v3 的事故主要通过：

`远处闷响 → 手机通知 → 查看详情`

传达。

问题不是事故规模小，而是人物和读者都停留在屏幕之外：
- 没有空间变化；
- 没有身体反应；
- 没有他人即时行为；
- 没有现场秩序突然失效；
- 没有“我刚才本来会在那里”的具体近失感。

因此悬念成立，冲击力不足。

## 新规则：重大事件必须具身化

当事故、死亡、暴力、灾害或重大异常第一次真正进入故事时，优先使用：

1. **声音/触觉先于解释**
2. **空间突然改变**
3. **普通人的反应**
4. **人物不得不行动**
5. **最后才给信息和解释**

不要默认：

`通知 → 理解 → 情绪`

优先：

`感觉到不对 → 现场发生 → 行动 → 看见后果 → 才知道发生了什么`

## 但不能靠夸张制造刺激

禁止：
- 为了抓人随便死人；
- 爆炸、血腥、尖叫堆叠；
- 主角突然英雄附体；
- 所有人像灾难片群众一样失去正常反应。

冲击来自：
> **真实现场 + 差一点发生在自己身上 + 后知后觉的异常。**

## CH001 v4 的新钩子结构

1. 封路通知出现，大家都把它当普通校园通知。
2. 沈既明绕路。
3. 金属撕裂声、地面震动、人群奔跑，让事故进入身体感受。
4. 他靠近现场，看到真实伤员和坍塌空间。
5. 官方事故通知在事故发生后才到。
6. 他回看旧通知：
   - 封路提醒 17:16
   - 官方事故通知 17:31
7. 真正悬念不是“楼为什么塌”，而是：
   > **谁提前十五分钟知道这里不能走？**

## 长篇适用原则

“平静生活 → 突然进入现场 → 事后发现更深异常”可作为重要事件的一种节奏手段，但不能每次复制同一模板。

Style Director 检查重大事件时，必须问：
- 人物有没有真正到场？
- 身体有没有感到变化？
- 空间有没有改变？
- 有无具体他人反应？
- 事件本身是否仍符合现实逻辑？
- 悬念是否落在真正需要调查的问题上？
