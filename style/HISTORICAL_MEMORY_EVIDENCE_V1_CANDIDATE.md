# Historical Memory Evidence v1 — 历史调查中的“记忆生态”

> 状态：CANDIDATE
>
> 来源：CH004南淞路现场测试。
>
> 目的：避免历史调查写成“找到知情人→知情人讲真相”。

---

# 一、历史事件不会以同一种方式被保存

同一件两年前的事，至少可能留下五类不同记忆：

## 1. 人的记忆
特点：
- 会忘；
- 会混日期；
- 会记住情绪或麻烦，不记得分钟；
- 会把后来知道的东西重新写进过去。

优点：
- 能提供当时的人为什么那样做。

缺点：
- 精度低；
- 容易后见之明。

## 2. 机构记录
特点：
- 结构化；
- 有流程；
- 但只记录机构当时认为值得记录的东西。

它最容易制造假象：
> 没写 = 没发生。

实际上可能只是：
> 没进入这个部门的记录口径。

## 3. 设备/系统记录
特点：
- 时间精确；
- 但不知道“为什么”；
- 版本升级以后字段意义可能变化；
- 可能存在迁移和映射。

设备精确不等于解释精确。

## 4. 后来复盘
特点：
- 比现场更完整；
- 但已经带有后来目标。

复盘可能把当年没人关心的事情重新提出来。

所以必须问：
> 这句话是现场当时写的，还是后来分析时加的？

## 5. 物理现场
特点：
- 最容易被误认为“客观”。

但城市会改造：
- 墙换过；
- 摄像头位置换过；
- 设备换代；
- 车道重画；
- 商户关闭。

今天的空间不是历史现场原样保存。

# 二、历史调查的核心不是“找到正确版本”

而是：

> **理解不同记录为什么不一样。**

这种不一致本身可能比某个单一“真相文件”更真实。

例如南淞路：

- 吴工记得有人会先口头喊绕行；
- 复盘摘要写“来源待确认”；
- 导航记录显示部分车辆提前改线；
- 今天现场已经换过设备。

四者可以同时成立。

# 三、人物在记忆生态里的天然偏好

## 沈既明
容易相信：
- 结构上能互相对齐的记录；
- 时间顺序；
- 可重复模式。

风险：
会过早把不同历史事件看成“同一种”。

## 程见微
容易先区分：
- 谁在什么时候写；
- 一手/二手；
- 原始/复盘；
- 事实/回忆。

风险：
可能把“无法证明”误当成“不应行动”。

## 陆峥
更相信：
- 找到当年的人；
- 谁知道谁；
- 哪个机构真做过事。

风险：
容易过高估计关键人物的记忆与关系网络。

## 宋亦衡
更关心：
- 哪份记录能用于安全判断；
- 如果历史解释错了，今天会造成什么风险。

# 四、后续2032黑箱的使用原则

2032不能出现一个“完整事故报告”让所有问题一次解决。

至少应由不同类型材料拼接：
- 某位工程师不完整记忆；
- 版本变更记录；
- 一段缺少上下文的系统日志；
- 后来修订的规范；
- 旧机房里仍存在的物理遗留；
- 某个机构内部复盘。

它们之间允许矛盾。

真正的历史感来自：
> 五年后的人已经无法完整回到那个夜晚。

---

# 五、禁止模式

不要写：

> “当年其实是这样的……”  
> 然后一位老人完整讲完两章历史。

不要让：
- 所有人记忆精确到分钟；
- 系统日志拥有全知视角；
- 后来的术语直接出现在早期材料中；
- 一份“最高机密文档”解决全部疑问。

历史不是一个藏起来的答案包。
