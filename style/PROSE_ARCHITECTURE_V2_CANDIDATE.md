# Prose Architecture v2 — Candidate

> 状态：CANDIDATE / 暂不替代main Style Bible
>
> 本版不是“反AI规则表”，而是正文生成的叙述模型。

# 1. 叙述核心

## 1.1 人物染色的有限第三人称

默认仍用有限第三人称。

但叙述者不是中性的摄像机。

进入谁的POV，叙述就轻微采用谁的：
- 注意顺序；
- 比较方式；
- 常用词汇；
- 情绪防御；
- 对他人的判断；
- 对世界的偏见。

### 沈既明POV
叙述更容易注意：
- 哪里不合理；
- 哪一步可以继续；
- 什么东西没有说清；
- 自己输了以后最不想承认什么。

但不能永远正确。

### 程见微POV
更容易注意：
- 用词的边界；
- 谁在偷换概念；
- 谁没有回答原问题；
- 关系中没有被说出的责任。

但她也会因为过度区分而错过整体。

这样人物辨识不需要靠口头禅。

# 2. 段落单位：注意团，而不是句子数

一个段落可以同时包含：
- 动作；
- 对话；
- 一个短联想；
- 环境；
- 一个无关判断。

只要这些内容属于同一轮注意力，就不必拆开。

禁止再使用：
- “每段2–5句”
- “短对白两轮上限”
- 固定对白比例
- 固定长短句比例

段落什么时候结束，只问：
> 人物的注意力是否真的转向了另一个对象/时间/关系？

# 3. 对话：分三种，不一刀切

## 3.1 关系对白
功能是：
- 试探；
- 挤兑；
- 示弱；
- 遮掩；
- 争面子；
- 维持亲密。

可以短，可以无效，可以答非所问。

## 3.2 任务对白
功能是交换事实、权限、安排。

应避免连续采访式问答。
可由叙述压缩，也可让一个角色一次说完整。

## 3.3 冲突对白
人物真正想说的和嘴上说的不是一回事。

这种对话允许反复、打断和短句，因为重点是关系变化而非信息效率。

判断标准不是“几轮”，而是：
> 对话结束后，人物之间有什么变了？

# 4. 信息进入正文的四阶段

重要信息默认不在第一次出现时被解释完。

## 阶段A：经过
作为普通环境/工作/生活的一部分出现。

## 阶段B：不协调
人物发现它和预期有一点对不上。

## 阶段C：回看
旧信息因为新事件被重新解释。

## 阶段D：升格
才成为明确线索、规则或世界观事实。

这样伏笔第一次出现时不需要“像伏笔”。

# 5. 私人性

每个主要POV都需要长期存在的私人线程。

不是人物简历，而是当前生活中真正占脑容量的东西，例如：
- 钱；
- 家人消息；
- 暧昧；
- 项目输赢；
- 宿舍关系；
- 对某个人的嫉妒；
- 睡眠；
- 一件拖了很久没办的小事。

私人线程可以：
- 和主线无关；
- 被主线打断；
- 反过来干扰主角正确判断。

禁止为了“人味”随机塞物件。

**私人性来自持续欲望，不来自随机细节。**

# 6. 偶然性

世界中允许出现三类偶然：

### 真偶然
永远不回收。

### 生活因果
对主线无用，但改变当天情绪、关系、行程。

### 误认伏笔
人物/读者以为重要，后来发现只是巧合。

但偶然不能用来解决核心冲突。

# 7. 危险场景

不再设机械“冷模式”。

危险发生时，自然产生三个变化：

1. **注意力收窄**
   人物无法同时理解全局，只能看到手边的人、物、出口、声音。

2. **解释延迟**
   事件过程中尽量不总结“这意味着什么”。

3. **身体和任务先于主题**
   谁受伤、要不要退、手机在哪里、门能不能开，比世界观重要。

事件结束以后，认知才慢慢赶上。

# 8. 技术与科学

技术解释遵循：
> **物 → 事 → 决策 → 必要解释**

而不是：
> 概念 → 定义 → 参数 → 事件。

科学异常必须尽量拥有可体验载体。

例如不要先说：
“系统产生跨版本持续责任状态。”

先让人物遇到：
- 人已经死了；
- 工单已关闭；
- 雨一来系统又重新追这件事。

# 9. 幽默

幽默来自：
- 人物性格；
- 关系历史；
- 自我防御；
- 社会处境。

不由旁白定期投放笑点。

重要原则：
> 同一个人物在不同关系里不一样好笑。

沈既明面对陆峥、梁慎之、程见微、母亲，讲话方式必须不同。

# 10. 主题

禁止主题句提前完成读者理解。

如果场景已经表达：
“流程结案和现实解决不是一回事”，
旁白不再写：
> 流程的结束从来不等于生活的结束。

让读者自己获得这一层。

# 11. 文体目标

正文应呈现：

- 读起来顺，但不光滑；
- 有作者控制，但看不见控制；
- 有信息密度，但不是所有句子都有任务；
- 有生活感，但不是随机生活素材；
- 有幽默，但不是所有人都机灵；
- 有哲学，但哲学总是晚于事件；
- 有悬念，但续读动力不只来自谜底。
