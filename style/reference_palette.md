# Reference Palette — 参考作品只取机制，不做拼贴模仿

> 状态：CONFIRMED

本项目不是“模仿某一个作家的表面句法”，而是把不同成熟作者/作品的优势拆成不同功能，再合成为自己的稳定叙事系统。

## 刘慈欣

### 借鉴
- 科学概念变成事件；
- 思想命题进入人物选择与现实后果；
- 宏大问题不必靠大段哲学议论；
- 技术必须改变生存条件、制度或判断。

### 不照搬
- 不要求模仿具体句式；
- 不要求照搬宏大冷峻感；
- 不让科学说明压倒人物生活。

## 马伯庸

### 借鉴
- 信息逐层释放；
- 人物行动推动信息揭示；
- 制度、流程、组织摩擦可以天然制造情节；
- 让复杂背景在“办事”过程中被读者理解。

### 不照搬
- 不要求历史悬疑口吻；
- 不把每一章都写成高密度机关解谜。

## 尾鱼

### 借鉴
- 即使设定虚构，具体场景也要像真实生活环境；
- 悬念来自人物不知道什么、误会什么、害怕什么；
- 生活细节与异常可以并存；
- 人物关系本身能承担悬念。

### 不照搬
- 不直接复制民俗悬疑结构；
- 不用神秘感替代科学因果。

## 余华

### 借鉴
- 普通人的生活质地；
- 乡土、人情、家庭与具体身体经验；
- 大时代最终必须落回具体的人；
- 苦难、荒诞、尴尬与温情不需要作者解释。

### 不照搬
- 不追求句式仿写；
- 不把整部作品变成纯现实主义乡土小说。

## 合成目标

暂定名称：

> **近身现实型科幻叙事**

工作定义：

> 用现实主义的身体、生活与组织细节建立可信地面；用因果推进与信息差建立可读性；让科学与哲学问题通过事件、选择和后果自然显形；直到局部生活本身承载文明尺度的问题。

## 与人物成长参考的边界

《哈利·波特》《龙族》《斗罗大陆》《斗破苍穹》主要进入**成长机制与长篇反馈系统**，而不是语言文风。

这些内容继续由 `characters/cast_framework.md` 和剧情架构管理，Style Agent 不得把其表面文风混进本项目。
