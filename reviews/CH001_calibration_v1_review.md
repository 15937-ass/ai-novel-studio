# CH001 Calibration Review — v1

> 对象：`drafts/calibration/CH001_v1.md`
>
> Verdict：**PASS_WITH_NOTES / 适合作为Style v1.0候选基准，但需要一轮Revision**

## 1. Style Director

### 优点
- 中长段落与连续流动叙事成立，没有碎段滥用。
- 科幻元素压在后台，校园生活与项目竞争先成立。
- 沈既明、陆峥、梁慎之已经能从语言区分。
- 没有开篇百科说明2037。
- 哲思只在“保留异常样本”这一处轻触，没有上升到AI意识。

### 需要修改

#### S-01 / minor
位置：梁慎之办公室
问题：
“有人会坐在那班车上，有人会等那张床……”虽然有效，但略有作者提前暗示后续“空床”单元的味道。

建议：
保留公共系统会影响真人的意思，但换成更普通、更不预告后文的例子。

#### S-02 / minor
位置：“不知道的时候，先别替它决定该不该消失。”
问题：
句子漂亮，主题性强。若保留，后续不能让全书人物持续说这种“可摘抄金句”。

建议：
可以保留作为梁慎之极少数的标志句之一。

## 2. Anti-AI Reviewer

### A-01 / pass
没有明显“三段式升华”“真正重要的是”“不是A而是B”式机械总结。

### A-02 / minor
“他不服，但又找不到哪个字能直接反驳”略像通用心理总结。

建议：
第二稿可以用具体动作替代一部分。

### A-03 / pass
陆峥不是工具性竞争者：
- 给咖啡；
- 主动发审批号；
- 实际能力被正文展示。
这有助于群像灰度。

## 3. Reality Anchor

### R-01 / pass
大学现实感较好：
- 项目名单；
- 答辩；
- 宿舍群收鞋；
- 接驳延误；
- 雨天绕路；
- 母亲消息。

### R-02 / major
北连廊结构事故必须在CH002给出现实原因。
不能让未来校园建筑无缘无故“为了剧情塌”。

建议候选工程原因：
- 连续强降雨导致既有结构缺陷暴露；
- 连廊改造后的排水/连接节点问题；
- 事故在事后有正常工程解释。

重点：
谜团是“为什么通知提前出现”，不是“连廊为何神秘坍塌”。

### R-03 / minor
2037的校园导航和导引屏与2020年代差别不大。
这是优点，不必为未来感强行加花活。

- 仍然立刻追陆峥的数据来源；
- 面对异常第一反应查发布信息。

### 陆峥
成立。
不能在后文突然退化成“抢资源的对手”。

### 梁慎之
成立，但S-01需降低预言感。

### 程见微
本章未出现，符合Contract。

## 5. Narrative Review

### 状态变化明确
开头：
> 沈既明没进项目。

结尾：
> 一条没人知道来源的通知可能刚刚救了人。

两个问题自然绑在同一天，没有硬拽世界观。

### 钩子强度
结尾“发布信息暂不可用”有效，但CH002必须迅速兑现：
- 有事故；
- 有真实核查；
不能连续几章只吊胃口。

## 6. 建议锁入Style Bible的候选参数

从本稿表现看，可以在Director认可后锁定：

- narrator温度：**中性偏暖，允许少量干幽默**
- 心理距离：**中近距离**，可进入即时判断，不做长篇自我分析
- 未来感：**低炫技**，只在功能变化时出现
- 对话：**现实口语 + 角色差异，不追求句句机锋**
- 段落：**中长段为主；高潮处才短段**
- 哲思：**每章最多少量高密度句，不连续升华**

3. 保留结尾结构。
4. 不增加未来科技炫技。
5. 第二稿仍控制在近身校园体验。
