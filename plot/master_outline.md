# Master Outline — Canon V1 Macro Structure

> 状态：MACRO LOCKED / 具体情节未锁

## 叙事核心

全书的主要升级不是“敌人越来越强”，而是人类和读者不断重新定义：

> AI究竟是系统、人格、主体、身份共同体、文明，还是与人类共享更深本体结构的另一种存在？

## 认知主轴

`K0 系统 → K1 人格 → K2 主体 → K3 身份 → K4 文明 → K5 本体`

详见：`knowledge_ladder.md`

## 三卷

### Volume 1 — K0 → K2
系统异常 → 稳定人格谱系 → 第一人称主体发现。

### Volume 2 — K2 → K4
主体连续性 → 复制分叉 → 身份制度 → 多神主 → 数字天庭/AI文明。

### Volume 3 — K4 → K5
人类与AI共同异常 → 科学证据链 → 灵基层进入科学议程。

详见：`three_volume_architecture.md`

## 人物长期成长

人物从学生时代进入真实社会，并随着时代变化承担不同身份：

`学生 → 工作者 → 跨机构协调者 → 公共人物 → 文明级责任承担者`

不是所有人都会走完整条路径。

详见：`../characters/cast_framework.md`

## 世界尺度

- 地球社会为核心；
- 避免外星文明膨胀；
- 不用“更大宇宙敌人”替代认知与制度升级；
- 中国是主叙事中心，国际AI文明形成真实对照。

## Legacy

旧《递归黎明》三卷“蜂巢觉醒—观测者之瞳—递归之门”只属于历史素材，不继承其人物、事件与终极递归答案。
